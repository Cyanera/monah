# مُونة — نسخة تجريبية (MVP)

«من فائض النعمة، نصنع الكفاية» — مبادرة مجتمعية في محافظة خليص لحفظ فائض الطعام الصالح وتوزيعه على الأسر المحتاجة.

React + Vite + TypeScript + Tailwind CSS v4 + Lucide. بلا Backend: البيانات تُحفظ في `localStorage`. الخط: ثمانية Serif Text (في `src/assets/fonts`).

## التشغيل محليًا

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # ينتج مجلد dist
npm run preview    # معاينة نسخة الإنتاج
```

## الصفحات (روابط Hash، تعمل على أي استضافة ثابتة)

| الرابط | الصفحة |
|---|---|
| `#/` | الرئيسية |
| `#/donate` | ساهم بفائض الطعام |
| `#/admin` | لوحة الإدارة التجريبية (غير محمية) |

## قواعد الأعمال المطبقة

- الطلب الجديد يبدأ دائمًا «طلب جديد» ولا يُعتمد تلقائيًا.
- الرفض يتطلب سببًا يظهر في القائمة والتفاصيل.
- «تم التوزيع» يتطلب تأكيدًا يدويًا من المسؤول.
- الإحصائيات (في الرئيسية واللوحة) تُحسب من البيانات المخزنة، وموسومة بأنها تجريبية.
- زر «إعادة تعيين البيانات التجريبية» في لوحة الإدارة يعيد البيانات الأصلية. كل البيانات الأولية وهمية.

## النشر مستقبلًا

`vite.config.ts` يستخدم `base: "./"` فيعمل مجلد `dist` على أي استضافة ثابتة (Netlify، Vercel، Cloudflare Pages، GitHub Pages) دون إعداد إضافي.
قبل الاستخدام التشغيلي الحقيقي يلزم: مصادقة وصلاحيات للوحة الإدارة، وقاعدة بيانات وخادم آمنان بدل `localStorage`، وسياسة خصوصية لبيانات المنشآت.

## التخصيص

- حسابات التواصل في التذييل: `src/config.ts` (القيم الفارغة لا تُعرض).
- البيانات التجريبية: `src/lib/seed.ts`.
- قواعد تغيير الحالة: `updateRequest` في `src/lib/store.ts`.
